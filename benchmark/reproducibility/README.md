# Reproducibility & Redaction

Published evaluation artifacts should make the research process reproducible without exposing credentials or restricted material.

Public capability labels include:

- Web Search
- Web Page
- SIJI Research API

Published artifacts should omit:

- API keys, cookies, tokens, and secret header values;
- non-public service endpoints;
- restricted source text;
- hidden model reasoning;
- infrastructure metadata unrelated to the research question.

Every key fact or relationship should retain provenance:

- SIJI;
- Web source;
- agent analysis.

The released artifact set should preserve the preregistered task/model/tool conditions, relevant timestamps, allowed request/result records, response hashes and RU where applicable, metrics, and the final report.
