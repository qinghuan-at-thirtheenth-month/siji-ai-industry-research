# Coverage & Unknowns

Coverage is part of the answer.

SIJI does not treat “no row returned” as proof that the real-world relationship does not exist.

Useful states include:

- **complete** — complete within the declared scope/snapshot for that domain;
- **partial** — usable data exists, but known gaps remain;
- **unknown** — completeness cannot currently be established;
- **unavailable / restricted** — availability/access is a separate axis from completeness;
- **unsupported / not found in scope** — the current declared evidence set does not establish the assertion;
- **conflict** — sources or assertions disagree and should not be silently merged.

Coverage must be read with the specific scope, object type, snapshot/data-as-of time and rights state. There is no single honest “SIJI is X% complete” number for all industries.

The examples in this repository are intentionally narrow. They demonstrate evidence semantics, not total market coverage.
