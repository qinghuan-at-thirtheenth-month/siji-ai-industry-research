# Evaluation Artifacts

A released evaluation should provide:

- `metrics.json` — values calculated from the preregistered metric definitions;
- `analysis.md` — evaluator analysis;
- provenance and traceability checks.

The analysis should explain observable differences in:

- research depth and network closure;
- identity continuity;
- relationship and business-stage accuracy;
- conditional-conclusion quality;
- next-verification quality;
- source traceability;
- Web rediscovery vs new-evidence search.

For the next-inflection case, industry and market-expectation conclusions are evaluated separately.

The evaluator may find positive, neutral, mixed, or negative effects from adding SIJI.
