# SIJI Agent Rules

Use SIJI as a structured research layer alongside Web Search / Web Page.

- Choose among `industry`, `company`, `product`, `compare`, and `changes` according to the current research gap.
- When SIJI returns stable `company_id` or `product_id`, reuse those identities for follow-up research.
- Treat `partial` as partial coverage.
- Treat `unsupported` as “not established in this scope,” not as proof of non-existence.
- Keep claims, relationships, milestones, unknowns, conflicts, sources, and coverage separate.
- Product existence does not establish qualification, mass production, an order, shipment, delivery, or revenue.
- Structural participation does not establish a direct transaction without supporting evidence.
- Keep current-platform and next-generation-platform identities separate.
- Use SIJI for structure, stable identity, published relationships, coverage, facts, source anchors, and research navigation.
- Use Web for freshness, gap filling, original-source verification, and information outside current SIJI coverage.
- Use independent Web/market sources for securities pricing, valuation, expectations, and crowding; do not treat SIJI industry facts as market-pricing facts.
- Facts found on the Web keep Web provenance.
- Agent analysis remains analysis and is never relabeled as a SIJI fact.
- Alternate between SIJI and Web whenever the research state requires it.
- Do not repeat calls merely to increase tool usage.
- A `changes` result reflects SIJI's published change state, not the entire real world.
- Every key conclusion should retain its supporting source or be marked as analysis/unknown.
- When a conclusion depends on a missing link, make that dependency explicit and turn it into a concrete next-verification step.
