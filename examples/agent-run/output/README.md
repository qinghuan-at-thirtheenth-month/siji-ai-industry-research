# Final Output Artifacts

A released run should provide:

- `research-report.md` — full research result;
- `research-summary.md` — concise synopsis.

The report should begin with the direct answer to the user's question, then separate:

- research scope and `data_as_of`;
- key conditional conclusions;
- evidence-backed propagation paths;
- product/platform generation identities;
- company participation;
- timeline/business stages;
- original sources;
- agent analysis;
- unknowns/conflicts/unsupported items;
- evidence gaps;
- alternative explanations;
- invalidation conditions;
- unresolved research frontier;
- concrete next-verification actions.

For the next-inflection case, the report must contain separate **industry** and **market-expectation** judgments.

Each evaluation is tied to its run context and should remain reproducible over time.
